## 🚀 Запуск

Для запуска необходимо открыть **3 консоли cmd** и выполнить в них следующие команды.

### Консоль 1

```cmd
команда_для_первой_консоли
```

### Консоль 2

```cmd
команда_для_второй_консоли
```

### Консоль 3

```cmd
команда_для_третьей_консоли
```
