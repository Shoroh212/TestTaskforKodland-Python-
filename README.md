# Cat Game


Для запуска необходимо открыть **3 консоли cmd** и выполнить в них следующие команды.

### Консоль 1

написать py server.py

### Консоль 2

написать py bot.py
### Консоль 3

написать py game.py
После чего отправить start телеграмм боту
